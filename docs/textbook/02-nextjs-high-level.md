# Chapter 2: Next.js at a High Level

## What Is Next.js

Next.js is a React framework for building production web apps with built-in routing, server rendering options, API routes, and deployment-friendly conventions.

## Who Made It

Next.js is created and maintained by Vercel, with contributions from the open-source community.

## Why It Matters for AI Apps

AI apps need:

- Fast UI iteration
- Secure server-side key handling
- API route support for orchestration
- Easy deploy paths

Next.js provides all of these in one framework.

## High-Level Building Blocks in This Project

- App route UI in src/app and src/components
- Server API orchestration in src/app/api/chat/route.ts
- Shared logic in src/lib

## Student Focus

Students should understand server and client boundaries. API keys and tool orchestration must stay on the server.
