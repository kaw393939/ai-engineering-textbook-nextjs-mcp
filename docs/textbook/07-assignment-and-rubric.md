# Chapter 7: Assignment Instructions and Rubric

## Assignment Goal

Build and explain an AI chat app in Next.js that uses MCP tools for arithmetic and validates behavior with real-LLM evals.

## Required Deliverables

1. Working chat UI and API route
1. MCP calculator server and client integration
1. Server-side enforcement for tool-backed arithmetic
1. Unit tests for deterministic logic
1. Real-LLM eval harness with pass/fail output
1. Short architecture write-up

## Suggested Milestones

1. Baseline Next.js app
1. Chat route with provider integration
1. MCP server/client wiring
1. Tool enforcement logic
1. Tests and evals
1. Reflection and documentation

## Rubric (100 points)

- Architecture correctness: 25
- MCP integration quality: 20
- Testing quality: 20
- Eval harness quality: 20
- Documentation and explanation clarity: 15

## Reflection Questions

- What failures were caught by evals but not by unit tests?
- Where did user direction change architecture decisions?
- Why is server-side enforcement critical in AI systems?
