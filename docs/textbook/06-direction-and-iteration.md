# Chapter 6: Prompting, Direction, and Iteration

## Human Direction as Engineering Input

In AI-assisted development, user instructions function like evolving product requirements.

## What Happened in This Project

The project evolved through clear direction changes:

- Start with a professional Next.js baseline
- Add chat behavior
- Replace form-based math with conversational MCP tools
- Enforce tool usage and remove unsupported claims
- Add real-LLM evals

## Why This Matters for Students

Students should learn to:

- Give precise constraints
- Detect misalignment quickly
- Iterate toward stronger architecture
- Require verification before accepting changes

## Practice Rule

When behavior is critical, define acceptance criteria and verify with executable checks.
